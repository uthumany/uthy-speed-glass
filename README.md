# Uthy Speed Glass

A native GNOME Shell extension for a floating, translucent network monitor. It reads Linux interface byte counters and shows live download and upload throughput in **decimal MB/s**—no speed-test service, account, API key, or telemetry required.

> **Build status:** the source and installable ZIP are reproducibly generated by project scripts. GitHub Actions validates pushes and packages tagged releases. This Ubuntu 24.04 sandbox is not the target Zorin desktop, so live GNOME Shell behavior is **not tested here**. See [Testing](docs/TESTING.md) and [known limitations](docs/TROUBLESHOOTING.md).

## Features

- Simultaneous download and upload readings from `/proc/net/dev`.
- Mini, compact, expanded, and minimized presentations; closing hides the card, and the panel menu can show it again.
- Drag-to-move, drag-to-resize, position pinning, monitor-edge clamping, and saved geometry.
- Optional animated meters and bounded recent-history graphs.
- NetworkManager D-Bus active-connection selection with route and sysfs fallbacks; automatic or manually selected Ethernet, Wi-Fi, USB-tethered, and visible virtual interfaces.
- Session averages, peaks, and RX/TX totals.
- Optional ping to the local IPv4 default gateway every ten seconds; off by default and no ping target is contacted while disabled.
- GTK4/Libadwaita preferences for transparency, colors, text size, radius, graph height, sampling interval, reduced motion, and interface selection.
- Per-user installation, safe removal, local automated tests, schema validation, packaging, and GitHub Actions workflows.

## Compatibility

The target is Zorin OS 18.1 Core, which Zorin identifies as based on Ubuntu 24.04 LTS and using GNOME Shell in Core/Pro editions. Zorin's public technical details do **not** state the exact GNOME Shell minor version, and the target machine was not available for discovery. Extension metadata declares GNOME Shell 45–50; implementation follows the modern ES-module extension and GTK4 preferences model. Confirm the actual system with `gnome-shell --version`, `gjs --version`, and `echo "$XDG_SESSION_TYPE"` before installing. Zorin Lite uses Xfce and is outside this extension's scope.

The system overview is documented at [Zorin OS technical details](https://zorin.com/os/details/); the implementation model follows the [GNOME JavaScript extension guide](https://gjs.guide/extensions/). Source facts and the unresolved target-version check are recorded in [Compatibility notes](docs/COMPATIBILITY_NOTES.md).

## Install

You can install the prebuilt ZIP from [GitHub Releases](https://github.com/uthumany/uthy-speed-glass/releases/latest) with **Extension Manager**, or use these commands (replace the ZIP path with where you downloaded it):

```bash
gnome-extensions install "/path/to/uthy-speed-glass@uthy.zip"
gnome-extensions enable uthy-speed-glass@uthy
```

To install from source, first clone the repository and enter its directory. If you already cloned it, `cd` to that checkout instead. These commands must be run from the repository root—the folder containing `scripts/` and `metadata.json`—because the script paths below are relative to that directory. A new Terminal normally starts in your home directory (`~`), not in the checkout.

```bash
git clone https://github.com/uthumany/uthy-speed-glass.git
cd uthy-speed-glass
bash scripts/install.sh
gnome-extensions enable uthy-speed-glass@uthy
```

The installer is per-user and does not use `sudo`. Open **Extensions** or **Extension Manager** to enable it if the `gnome-extensions` command is unavailable. On Wayland, a Shell restart normally means logging out and back in; do not use the X11 `Alt`+`F2`, `r` reload path on Wayland.

To install from a locally built ZIP instead:

```bash
bash scripts/package.sh
gnome-extensions install "$PWD/dist/uthy-speed-glass@uthy.zip"
gnome-extensions enable uthy-speed-glass@uthy
```

Open preferences from the floating card or the GNOME panel menu. The panel menu can show/hide the card, pause/resume monitoring, reset session statistics, and open preferences.

## Reading the numbers

The extension computes:

```text
download_MBps = RX-byte-delta / elapsed-seconds / 1,000,000
upload_MBps   = TX-byte-delta / elapsed-seconds / 1,000,000
```

`MB/s` is megabytes per second. It is not `Mbps` (megabits per second); 8 Mbps is approximately 1 MB/s. The first sample, an interface change, a counter reset, or a long suspend gap establishes a fresh baseline, so the widget shows `-- MB/s` instead of inventing a reading.

## Preferences

- **Sampling:** 500, 1000, or 2000 ms; automatic or a currently visible interface; mini, compact, or expanded default layout.
- **Appearance:** surface opacity, download/upload hex colors, font size, corner radius, graph height, and graph visibility.
- **Behavior:** remember geometry, reduce motion, and optional local-gateway ping.

Move the widget from its title strip and resize it from the lower-right handle. Pinning locks movement but does not stop sampling. Reset session statistics from the expanded controls or panel menu.

## Privacy and resource use

Core monitoring is local and offline-capable. No traffic values or interface names are sent anywhere. Optional ping is disabled by default and sends one ICMP echo to the current IPv4 default gateway every ten seconds only when enabled; IPv6-only gateway discovery is not implemented. Sampling uses one GLib timer; history is capped at 120 samples. The only subprocess is the optional, non-overlapping ping process, invoked with an argument array (never through a shell).

## Development

```bash
bash scripts/validate.sh
bash scripts/package.sh
bash scripts/package-source.sh
node --test tests/*.test.js
```

The runtime itself has no Node.js dependency; Node is used only by deterministic development tests. `package.sh` creates the installable extension ZIP; `package-source.sh` creates a full project archive containing source, tests, documentation, scripts, and CI configuration. See [Development](docs/DEVELOPMENT.md), [Architecture](docs/ARCHITECTURE.md), [UI specification](docs/UI_SPECIFICATION.md), and [Troubleshooting](docs/TROUBLESHOOTING.md).

## Uninstall

Run from the GNOME user session:

```bash
bash scripts/uninstall.sh
```

It disables this extension UUID first when enabled, then removes only its per-user extension directory. It refuses to remove files if the GNOME extension CLI is unavailable.
